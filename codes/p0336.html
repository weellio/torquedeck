P0336

Ignition system and misfireGeneric code (all makes)

What P0336 means

Your car's computer set P0336: Crankshaft position sensor A range/performance. It belongs to the ignition system and misfire group of codes. It is a generic code, so it means the same thing on every make. The check engine light usually comes on once the fault has been seen on two drives in a row. Until then it shows up as a pending code.

Can I keep driving? The engine can stall or refuse to start. Get it fixed before a long trip.

Common causes

  • Failed crankshaft position sensor
  • Damaged reluctor ring
  • Wiring or connector problem

Fix the cheapest, most likely cause first. Clearing the code without a repair only turns the light off until the fault comes back.

Check it yourself

If the RPM reading drops to zero or jumps while driving, the crank sensor signal is cutting out.
