P0440

EVAP system malfunction

Emission controlsGeneric code (all makes)

What P0440 means

Your car's computer set P0440: EVAP system malfunction. It belongs to the emission controls group of codes. It is a generic code, so it means the same thing on every make. The check engine light usually comes on once the fault has been seen on two drives in a row. Until then it shows up as a pending code.

Can I keep driving? Usually safe to drive. The car may run normally, but it will not pass an emissions test until this is fixed.

Common causes

  • Loose or worn gas cap
  • Leaking EVAP hose or valve
  • Failed fuel tank pressure sensor

Fix the cheapest, most likely cause first. Clearing the code without a repair only turns the light off until the fault comes back.

Check it yourself

Start with the gas cap. Then read the EVAP readiness monitor on the Car tab.

Torque Deck reads P0440 with a cheap Bluetooth OBD2 adapter. It also shows the freeze frame (engine conditions at the moment the code set) and the live data you need to narrow it down.
