P0491

Secondary air injection (Bank 1)

Emission controlsGeneric code (all makes)

What P0491 means

Your car's computer set P0491: Secondary air injection (Bank 1). It belongs to the emission controls group of codes. It is a generic code, so it means the same thing on every make. The check engine light usually comes on once the fault has been seen on two drives in a row. Until then it shows up as a pending code.

Can I keep driving? Usually safe to drive. The car may run normally, but it will not pass an emissions test until this is fixed.

Common causes

  • Failed secondary air pump
  • Stuck check valve
  • Blown fuse or bad relay

Fix the cheapest, most likely cause first. Clearing the code without a repair only turns the light off until the fault comes back.

Check it yourself

This system only runs for a minute or so after a cold start.

Torque Deck reads P0491 with a cheap Bluetooth OBD2 adapter. It also shows the freeze frame (engine conditions at the moment the code set) and the live data you need to narrow it down.
