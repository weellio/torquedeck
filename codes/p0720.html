P0720

Output speed sensor circuit

TransmissionGeneric code (all makes)

What P0720 means

Your car's computer set P0720: Output speed sensor circuit. It belongs to the transmission group of codes. It is a generic code, so it means the same thing on every make. The check engine light usually comes on once the fault has been seen on two drives in a row. Until then it shows up as a pending code.

Can I keep driving? Shifting may be harsh or the transmission may go into limp mode. Get it checked soon.

Common causes

  • Failed transmission speed sensor
  • Wiring or connector problem
  • Low transmission fluid

Fix the cheapest, most likely cause first. Clearing the code without a repair only turns the light off until the fault comes back.

Check it yourself

Read codes again after a drive to see if it comes back.
