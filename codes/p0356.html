P0356

Ignition system and misfireGeneric code (all makes)

What P0356 means

Your car's computer set P0356: Ignition coil F primary/secondary circuit. It belongs to the ignition system and misfire group of codes. It is a generic code, so it means the same thing on every make. The check engine light usually comes on once the fault has been seen on two drives in a row. Until then it shows up as a pending code.

Can I keep driving? Usually causes a misfire. If the engine shakes or the light flashes, stop driving soon.

Common causes

  • Failed ignition coil
  • Damaged coil connector or wiring
  • Blown fuse or bad coil power supply
  • Engine computer driver fault (rare)

Fix the cheapest, most likely cause first. Clearing the code without a repair only turns the light off until the fault comes back.

Check it yourself

Read codes for a matching misfire code (P030x). Check the connector on that coil.
