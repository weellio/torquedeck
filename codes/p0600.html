What P0600 means

Your car's computer set P0600: Serial communication link. It belongs to the engine computer and outputs group of codes. It is a generic code, so it means the same thing on every make. The check engine light usually comes on once the fault has been seen on two drives in a row. Until then it shows up as a pending code.

Can I keep driving? Get it checked. Start by making sure the battery and grounds are good.

Common causes

  • Engine computer software or internal fault
  • Poor ground or low battery voltage
  • Water damage to the computer

Fix the cheapest, most likely cause first. Clearing the code without a repair only turns the light off until the fault comes back.

Check it yourself

Run the Battery & charging test first. Low voltage can cause false module codes.

Torque Deck reads P0600 with a cheap Bluetooth OBD2 adapter. It also shows the freeze frame (engine conditions at the moment the code set) and the live data you need to narrow it down.
